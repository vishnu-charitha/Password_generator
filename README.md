#  CLI Password Generator

A Command-Line Interface (CLI) based Password Generator built using Python that generates secure and random passwords with customizable length, character selection, password strength checking, input validation, and clipboard support.

##  Features

* ✅ Generate secure random passwords
* ✅ Custom password length
* ✅ Include uppercase letters
* ✅ Include lowercase letters
* ✅ Include numbers
* ✅ Include symbols
* ✅ Password strength analysis
* ✅ Clipboard integration
* ✅ Input validation
* ✅ Exclude specific characters

##  Technologies Used

* Python
* Random Module
* String Module
* Pyperclip

##  Installation

Clone the repository:

```bash
git clone https://github.com/vishnu-charitha/Password_generator.git
```

Move into the project folder:

```bash
cd Password_generator
```

Install dependencies:

```bash
pip install -r requirements.txt
```

##  Run the Project

```bash
python main.py
```
